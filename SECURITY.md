# Security Policy

## Reporting a vulnerability

Please report security issues privately via GitHub's
[private vulnerability reporting](https://github.com/VDV001/kb-engine/security/advisories/new)
rather than opening a public issue.

Include a description, reproduction steps, and the affected version/commit.
You can expect an initial response within a few days.

## Supported versions

The project is pre-1.0; only the latest release and `main` are supported.
