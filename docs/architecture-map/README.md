# Карта архитектуры и сценариев

Интерактивная карта того, как движок работает: слои, узлы и **сценарии** — не модули, а действия («владелец записывает трату», «страница сама говорит, что отстала»).

Открыть: `docs/architecture-map/index.html` в браузере. Страница самодостаточна — данные вшиты, внешних запросов нет.

## Зачем разделены три файла

| файл | что это |
|---|---|
| `map.json` | сама карта: слои, узлы, сценарии по шагам. Правится, когда меняется код |
| `template.html` | вёрстка и поведение страницы. Правится, когда меняется внешний вид |
| `index.html` | собранная страница, `build.py` кладёт данные в шаблон |
| `validate.py` | проверка карты против репозитория |

Держать данные и вёрстку в одном файле означало бы, что правка одного из двух ломает второй.

## Правило, на котором всё держится

**Каждый шаг несёт ссылку `file:line`, и валидатор её проверяет** — открывает файл на этой строке и ищет там заявленный вызов. Схема, нарисованная по здравому смыслу, выглядит ровно так же убедительно, как схема, собранная по коду; отличить их можно только механической проверкой.

Связь, которую вывести из кода не удалось, помечается `"unverified": true` и рисуется пунктиром с подписью. **Выдуманная стрелка хуже отсутствующей** — она отнимает у читателя возможность заметить пробел.

Раздел `gaps` обязателен и не может быть пустым: инструмент должен вслух называть, чего он НЕ проверял.

## Как пересобрать

```sh
python3 docs/architecture-map/build.py
```

Валидатор запускается сам, и при нарушениях страница не собирается. Отдельно:

```sh
python3 docs/architecture-map/validate.py docs/architecture-map/map.json .
python3 docs/architecture-map/validate.py docs/architecture-map/map.json . --self-test
```

`--self-test` подсаживает в карту шесть заведомо ложных записей (несуществующий файл, строка за пределами файла, вызов которого там нет, ссылка на несуществующий узел, пустые `gaps`, подтверждённый шаг без источника) и требует, чтобы валидатор поймал каждую. Без этого «валидатор прошёл» не значит ничего.

## Что в карте намеренно отсутствует

- **Числа о содержимом личной базы владельца.** Репозиторий публичный: числа о продукте (размер файлов, количество маршрутов, версии) остаются, объёмы личных данных — нет.
- **Гейты `scripts/gates`** — это процесс разработки, а не работа продукта.
- **`file:line` у файлов данных и у людей.** У данных и у человека нет строки в репозитории; выдуманная ссылка была бы ровно тем враньём, от которого защищает валидатор.

## Когда карта устаревает

Она устаревает молча — это её главный недостаток. Валидатор ловит **переехавшую строку** (вызова не окажется рядом с указанной), но не ловит **новый сценарий**, который в карту не попал. Правило простое: меняешь путь, по которому идут данные, — правь `map.json` в том же PR.
