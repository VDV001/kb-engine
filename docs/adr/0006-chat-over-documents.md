# ADR-0006 — Чат над документами: один клиент, два пути к контексту, история у окна

- Status: accepted
- Date: 2026-11-06
- Issue: #436

## Context

Окно DVK — агентная база знаний, а не только поиск (решение владельца 05.11): человек
спрашивает, модель отвечает по его записям и файлам со ссылками, к чату можно вернуться.

Ответы владельца, 06.11.2026:

- историю чатов хранить **локально у окна**; синхронизация между устройствами — позже (#439);
- контекст — **оба пути**: маленькой локальной модели документы находит окно, сильная
  (Sonnet, Opus) ищет сама инструментами — «гибкость, а с хорошими моделями качество и точность»;
- модели — **ключ Vercel AI Gateway** владельца и **Ollama** локально.

Замер 06.11: Gateway `https://ai-gateway.vercel.sh/v1/chat/completions` принимает `tools`
в формате OpenAI и отвечает `tool_calls` (Haiku 5.5). Ollama отдает тот же протокол.

## Decision

1. **Один клиент** `internal/adapter/llm` — OpenAI-совместимый `/chat/completions`, без SDK.
   Ключ — только на https или этот Мак (Ollama), в ошибки и журнал не попадает, текст ответа
   с ошибкой не читается (провайдер мог повторить в нем ключ). Ключ хранится в Связке ключей,
   как токен kb-сервера.
2. **Usecase** `internal/usecase/chat` с портами `Searcher` и `Model`. Режимы:
   - `context` — окно ищет само (общая выдача источников), первые 8 документов по 1 500
     символов уходят в запрос с номерами, модель отвечает со ссылками `[n]`; документы чата —
     процитированные, без ссылок — все найденные;
   - `tools` — модель зовет поиск и чтение сама (следующий PR), каждый прочитанный документ —
     в документах чата.
   Режим берется из профиля модели и переключается в настройках.
3. **История** — файл на чат рядом с config.json окна, 0600.
4. Окно говорит вслух: найденные документы уходят выбранной модели (для Ollama — никуда
   с этого Мака).

## Consequences

- Новый провайдер с тем же протоколом (llama.cpp server, OpenRouter) подключается адресом,
  без кода.
- Поиск в режиме `context` идет по последнему вопросу: уточнение без существительного
  находит не то (`ponytail:` в `chat.go`); режим `tools` это снимает.
- Gateway с пустым балансом отвечает 402/403 — окно называет это «нет кредитов» или
  «ключ не принят», а не сбоем.
